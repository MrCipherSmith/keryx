# SAC Policy Experiment Fixture Corpus

This directory is a synthetic, offline Phase 5 mechanism fixture. It contains
no real actor, workspace, prompt, transcript, reasoning, secret or retrieved
content.

- `receipts.jsonl` is an ordered AccessReceipt hash chain.
- `outcomes/*.json` are separate completion-gate artifacts. Corpus rows bind
  their canonical JSON SHA-256 digests; receipt self-report is ignored.
- `artifacts/deterministic-baseline.json` and `artifacts/candidate.json` are the
  exact immutable synthetic programs compared by the evaluation fixture. Their
  SHA-256 byte digests, not placeholder values, are the version pins.
- `artifact-manifest.json` records the byte digest and repository-relative
  reference for every executable or sandbox-control artifact.
- `sandbox/allowed-control.json` and `sandbox/denied-escape-control.json` are
  the paired owner-side containment observations. Generated execution receipts
  bind these control bytes, the request, candidate and sandbox profile.
- `corpus.json` contains only allowlisted, bucketed features and corpus-scoped
  pseudonyms. Its `quarantine` array is empty for this positive fixture;
  negative quarantine cases are exercised in `policy-experiment.test.ts`.
- `manifest.json` publishes provenance, selection, redaction, quarantine,
  deterministic split and adversarial metadata.
- `evaluation-report.json` records the exact candidate/baseline/corpus/sandbox
  pins, the baseline's executed results, paired harness-owned containment
  controls and passing synthetic holdout/adversarial gates.
- `sandbox/execution-receipts.json` contains the owner-issued, hash-linked
  receipts for both deterministic candidate executions of every corpus case.

The corpus proves reproducibility and safety gates only. It does not authorize
or enable a learned policy, and it is not evidence of production improvement.

Regenerate with `bun scripts/generate-sac-policy-experiment-fixtures.ts` or
verify byte-for-byte reproducibility with the same command plus `--check`.

Fixture regeneration must be byte-for-byte deterministic: load the receipt and
outcome inputs, hash the committed baseline/candidate/control artifacts, build
the corpus, execute each case twice through the owner sandbox adapter, format
the report with the canonical formatter, then compare every regenerated byte
and corpus/split/report/artifact digest with the committed files. Until that
generator lands, digest changes must fail fixture verification rather than be
accepted by manually updating pins.
