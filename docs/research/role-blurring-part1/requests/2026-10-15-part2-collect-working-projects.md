## Правила

Все правила финального сбора остаются. Для рабочих проектов главное:

- в git только `raw/decisions-<host>.jsonl` и `raw/journal-<host>.md` с числами;
- никогда не записывать ветку, HEAD, remote, имя репозитория или организации, номера задач и PR, имена основных веток, список flow проекта, пути;

- без `git stash`, `git add -A`, `git add .`, `git commit -a`; без строк `Co-Authored-By` и ссылок на сессию;
- PR не сливать.
