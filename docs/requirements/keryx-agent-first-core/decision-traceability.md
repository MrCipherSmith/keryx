# Матрица решений и acceptance
Version: 0.1.2

Статус: **spec ready**. Технические контракты — **proposed**; их runtime-реализация этим пакетом не подтверждается.

## Статус и правило покрытия

49 исходных ID сохранены без переименования. Каждая строка одновременно определяет обязательный сценарий `AC-<ID>`: дано указанное исходное состояние, при выполнении операции ожидается описанный результат. В каждой волне реализация обязана добавить положительную и отрицательную проверку, а там, где есть crash/concurrency, отдельную fault-injection проверку. Это план проверок, не заявление, что тесты уже написаны или пройдены.

Принятое направление и позднейшее уточнение имеют приоритет над старым исследовательским предложением. Эта таблица содержит полное публично допустимое содержание решений, не требует доступа к исходному обсуждению и не переносит частные экспериментальные результаты. Подробности технического решения по ссылкам имеют статус proposed.

## Проверка завершения

Для каждой строки сохраняются ссылка на реализующий diff, версия runtime, фактический результат acceptance и область проверки. Пустая ячейка evidence означает незавершённую реализацию. Ни наличие этого пакета, ни согласование направления, ни зелёный старый audit не закрывают строку. Детерминированный contract-pass и внешняя оценка пользы — отдельные outcomes.
