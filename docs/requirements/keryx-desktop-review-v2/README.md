# Keryx Desktop Review v2 · разделение Pull Requests и Reviews
Version: 0.1.2

**Статус — этап 0 реализован на ветке `feat/desktop-review-v2-stage0` (Flow 516, PR #1294, ожидает слияния); этапы 1–4 — draft, не реализованы.** Пакет описывает целевое состояние и план перехода. Всё, что названо «сегодня», проверено по коду на коммите `1b994df18`; всё остальное — планируемое.

## Назначение

Review v1 поместил на одну карточку две сущности с разными жизненными циклами: pull request из GitHub и ревью Keryx. Из-за этого карточки меняют колонку и порядок от событий, не связанных с PR, фильтры дают неожиданный результат, а ревью теряет связь с собой, когда автор PR добавляет коммит. v2 разделяет их:

- **Pull requests** и **Issues** — срез работы в GitHub. Колонки, сортировка и фильтры зависят только от GitHub.
- **Reviews** — сущность Keryx рядом с Flows: одно ревью на PR и ревьюера, с раундами, сквозными находками и историей публикаций.
- Карточки PR и Issue несут только ссылки на работу Keryx — ревью, Flow и сессию — и кнопки её начать.

## Область

Входит: вкладки Pull requests, Issues и новая Reviews в Desktop; модель Review поверх существующих запусков; поведение ревью при новом коммите в PR; привязка сессий к PR и Issue; единый реестр ревью для Desktop и сессии агента.

Не входит: новый движок ревью, изменение состава ревьюеров и содержания волн review-orchestrator (добавляются только сверка head между волнами и процедура «head сдвинулся»), изменение формата пакета раунда, серверная очередь, провайдеры кроме GitHub, редактирование PR и Issue из Desktop (создание, merge, смена меток).

## Связанные модули

- [Пакеты управляемого ревью](../managed-review-feedback-loop/README.md) — пакет раунда, который v2 использует без изменений формата.

## Расхождение, замеченное при подготовке

README v1 говорит, что публикацию выполняет человек через GitHub, PRD v1 — что она выполняется через ссылки в GitHub. В коде публикация из Desktop уже есть (`ReviewPublishDialog`, `keryx review desk-publish`). v2 описывает публикацию как существующую возможность; документы v1 этот пакет не правит.
