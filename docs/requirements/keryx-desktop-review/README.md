# Keryx Desktop Review v1
Version: 0.1.0

**Статус — реализовано в рабочей ветке, пройдена приёмка v1 на macOS.** Доска, ручное ревью, локальный вотчер и правила автозапуска соответствуют Flow 496–499 основного checkout. Журнал приёмки содержит результаты реальных прогонов, проверки на управляемых событиях и условия полевой проверки.

| Документ | Для кого и зачем |
|---|---|
| [PRD](prd.md) | Продукт и разработка. Пользователи, сценарии, границы v1 и признаки успеха |
| [Спецификация](specification.md) | Разработка и QA. Источники данных, общий запуск review-orchestrator, правила и восстановление |
| [Приёмка на GitHub](live-acceptance.md) | Проверка требований на реальном PR, результаты и оставшиеся условия выпуска |
| [План реализации](implementation-plan.md) | Команда поставки. Четыре этапа, зависимости и демонстрация на выходе каждого |

В область v1 входят GitHub, локальный Keryx и macOS Desktop. Просмотр, настройка и запуск доступны в Desktop. Фоновые проверки продолжаются на работающей машине после полного выхода из приложения. Публикацию ответов и решений выполняет человек через GitHub. Общая серверная очередь и эксперимент с PR-Agent относятся к последующим версиям.

Основания и смежные модули — [концепция Review](../../analysis/desktop-review-board.md), [доска Flows](../keryx-desktop-client/flows-board.md), [пакеты управляемого ревью](../managed-review-feedback-loop/README.md) и [процесс review-orchestrator](../../../.metaproject/skills/gdskills/review/review-orchestrator/SKILL.md).
