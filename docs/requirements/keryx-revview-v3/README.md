# Keryx Review V3
Version: 0.3.0

Статус: **spec ready — решения D1–D7 приняты пользователем; реализация запущена отдельным запросом пользователя; финальная проверка в процессе**.
Дата: 2026-11-05. Идентификатор пакета `keryx-revview-v3` сохраняет написание из запроса пользователя.

## Назначение

Ускорить глубокое ревью через подготовку общего контекста, план покрытия и иерархию главный → генералы → солдаты. Главный может назначать солдат напрямую. Процесс остаётся `review-orchestrator`; отдельная сущность сабагента не подменяет skill или runtime.

## Границы

Первый выпуск включает native и Keryx runtime как внешнего генерала; остальные process adapters принимаются после capability-проверки, Pi отложен. В scope входят Keryx Shell/Hub Session и внешние harness через адаптеры. Не включены изменение flow-orchestrator, рекурсивные генералы произвольной глубины, автономная публикация/merge и изменение авторизации пользователя. Реализация ведётся в этой worktree по отдельному запросу пользователя; фактический статус и ограничения приведены в отчёте реализации.

Четыре сущности и архитектурные решения приняты; числа лимитов приняты как начальный профиль для проверки, а не как текущие настройки или доказанная производительность. Полный паритет объявляется только после capability-проверки конкретного runtime.
