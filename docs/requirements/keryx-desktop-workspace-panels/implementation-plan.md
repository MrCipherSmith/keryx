## Этап 1 — Внимание (R1–R4)

1. **Spike S0:** собрать приложение с `tauri-plugin-notification`, проверить, что приходит при клике по уведомлению на macOS. Записать результат; если данных клика нет — делать путь B (спецификация §6.1.3).
2. Rust: `attention_report`, `attention_open`, учёт в `ProjectWindows` по всем окнам, значок, уведомления, звук, `AttentionSettings`; тесты подсчёта и подавления.
3. Веб-слой: отчёт из `useAcpSession` (ожидания, показанная сессия, конец хода). Rust: локальный опрос вопросов ревью раз в 60 с на проект, без GitHub. Если после слияния #1256 в keryx нет локального запроса ожидающих вопросов, этот этап добавляет его сам: `keryx review runs --awaiting-answer --json` поверх `pendingQuestions` (`src/review/desk-run-store.ts`).
4. Группа «Needs attention» в `groupSessions`; `SessionSidebar` передаёт метки.
5. Блок «Attention» в Settings → Sessions.

Демонстрация: два окна, три проекта, приложение не в фокусе, два уведомления, значок «2», клик ведёт в нужную сессию.

## Этап 2 — Контекст у композера (R8)

- Мини-индикатор в тулбаре композера из `conv.usage`; меню «Compact» и «Details».

Демонстрация: длинная сессия, индикатор в зоне предупреждения, «Compact» уменьшает заполнение после следующего вызова.

## Этап 3 — Вкладка «Changes» (R5–R6)

- Команды `git_changes`, `git_file_diff` с `PanelRoots::require_project` и проверкой пути по ответу `git_changes`; тесты на фикстуре с удалённым и переименованным файлом.
- Вкладка `changes`: список, дифф, нумерация, выбор строк.
- Вид `line-comment` в `useChatAttachments`; отправка текстом «Line comments», без `untrusted`.
- Клик по счётчику изменений в футере открывает вкладку.

Демонстрация: агент правит три файла и удаляет один, пользователь оставляет два замечания, агент в `auto` исправляет по ним без запросов подтверждения.

## Этап 4 — Вкладка «Files» и `@` (R7)

- Команды `project_files`, `project_file_read` с `require_project`.
- Вкладка `files`: дерево, поиск, просмотр; режим `@` в попапе #1254.

Демонстрация: `@spec` в композере, выбор пути, агент читает файл.

## Этап 5 — Нативные изображения (R9)

После того как flow 493 объявит `promptCapabilities.image: true`:

- Desktop читает `promptCapabilities`; при `true` изображение уходит блоком `image`, иначе — путём, как в #1254.
- Ошибка «модель без зрения» в ленте с действием «Send as file».

Демонстрация: скриншот ошибки ⌘V, модель описывает ошибку по картинке; после повторного открытия сессии картинка в ленте.

## Проверки каждого этапа

`cd apps/desktop && bun test src`, `tsc`, `cargo test` и `clippy` для `src-tauri`. Ручная проверка в собранном приложении — владелец.
