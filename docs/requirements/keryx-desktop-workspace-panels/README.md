## Назначение

Desktop показывает живую сессию keryx, но не помогает заметить, что сессия ждёт человека, и не показывает, что агент поменял в файлах. Пакет добавляет:

1. **Внимание.** Системное уведомление, счётчик на значке Dock и звук, когда сессия ждёт ответа или закончила ход в фоне. Группа «Ждут вас» вверху списка сессий.
2. **Вкладка «Изменения».** Изменённые файлы проекта, дифф по файлу и комментарий к строке, который уходит агенту вложением.
3. **Вкладка «Файлы» и `@`-упоминания.** Дерево проекта, просмотр файла только на чтение, вставка `@путь` в композер.
4. **Заполнение контекста у композера** и действие «Сжать» (`/compact`).
5. **Картинки во вложениях.** Вставка скриншота и перетаскивание изображения в композер. Нужна доработка keryx: сейчас ACP-агент объявляет `promptCapabilities.image: false`.

## Область и не-цели

В области: macOS-приложение `apps/desktop`, протокол ACP между приложением и `keryx acp --profile shell`, путь промпта keryx для изображений.

Не входит:

- редактирование файлов в приложении (вкладки только читают);
- запись в git из вкладок (stage, commit, revert);
- полноэкранный редактор диффа и тяжёлые редакторы кода в бандле;
- уведомления на телефон и внешние каналы — это [Remote Control](../../../.metaproject/wiki/architecture/remote-control.md) и Hub;
- аудио во вложениях.
