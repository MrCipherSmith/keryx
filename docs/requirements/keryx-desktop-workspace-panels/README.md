## Назначение

Desktop показывает живые сессии keryx, но не помогает заметить, что сессия ждёт человека, и не показывает, что агент поменял в файлах. Пакет добавляет:

1. **Внимание.** Учёт ожидающих сессий в Rust по всем проектам во всех окнах: системное уведомление, счётчик на значке Dock, звук, группа «Needs attention» вверху списка сессий. После #1256 — и вопросы ревью, ожидающие ответа.
2. **Вкладка «Changes».** Изменённые, в том числе удалённые, файлы проекта, дифф по файлу и замечание к строке, которое уходит агенту текстом: путь, строки, замечание.
3. **Вкладка «Files» и `@`-упоминания.** Дерево проекта, просмотр файла только на чтение, режим `@` в попапе композера из #1254.
4. **Заполнение контекста у композера** и действие «Compact» (`/compact`).
5. **Нативные картинки.** Пока keryx не принимает изображения, они уходят путём, как в #1254; когда keryx объявит `promptCapabilities.image: true` (flow 493), Desktop отправит их блоком `image`.

## Область и не-цели

В области: macOS-приложение `apps/desktop` и его использование ACP.

Не входит:

- нативный ввод изображений в keryx (flow 493) и способ вложения файлов (#1254);
- редактирование файлов в приложении (вкладки только читают);
- запись в git из вкладок (stage, commit, revert);
- полноэкранный редактор диффа и тяжёлые редакторы кода в бандле;
- уведомления на телефон и внешние каналы — это [Remote Control](../../../.metaproject/wiki/architecture/remote-control.md) и Hub;
- аудио во вложениях.
