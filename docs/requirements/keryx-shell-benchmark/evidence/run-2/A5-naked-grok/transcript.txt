     ───

     Requirements & degradation

     Long-term semantic features need Ollama + nomic-embed-text. Without Ollama:

     • Bot still runs
     • Embeddings can be null
     • /recall / semantic search degrade
     • Reconciliation falls back to plain insert
     • Summaries may still be generated, but not usefully embedded for search

     ───

     Design notes from docs

     • LLM reconciliation instead of exact-string dedup (Haiku for cost)
     • Soft deletes + per-type TTLs for cleanup without immediate loss
     • pgvector HNSW for ANN cosine search
     • memory/ as foundation — migrations live in memory/db.ts; no separate ORM
