  The transitive tier does not break at compile time. CONFIG is a value, not a type that flows outward, so a field change stops at level 1. What level
  2–4 inherit is a runtime coupling: config.ts runs EnvSchema.safeParse(process.env) at module load and calls process.exit(1) on failure
  (config.ts:125-141). Any of those 105 files, imported anywhere, boots that validation. So:

  - Rename or retype a field → breaks only the level-1 files that name it. Small.
  - Add a new required field (.min(1) with no default) → breaks all 105 at startup, plus every process that imports any of them. That's the change
  with real blast radius.
