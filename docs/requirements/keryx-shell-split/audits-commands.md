# Audits in the src/commands test files

Part of the [source-text audit inventory](source-text-audit-inventory.md) for the
[shell god-file split](README.md). Read the inventory first: it carries the
column meanings, the three audit kinds, and the four findings that cut across
all four detail files.

Compiled at flow 276 against `origin/main` at `398acb4a`.


Scope note (read first): `src/commands/shell.ts` has THREE relevant top-level shapes:

- `runShell(io: ShellIO, deps: ShellDeps)` — **exported**, line 601–1051. The
  already-injectable "chat" core. It independently re-implements almost the
  same bus-join/leave, lease-watch, and `/exit`|`/bus`|`/new`|`/compact`
  command handling that `runAgentRepl` has (compare: `leaseWatch` at 632 vs.
  1947; `busWorking` at 682 vs. 2034; `joinBus` at 690 vs. 2049; the command
  switch at 776–1042 vs. 2230–2527). This copy IS already driven behaviourally
  in `shell-bus.test.ts` (its "runShell bus …" describes, ~line 1–551) and
  `shell-lease.test.ts` via fake `lines`/`shellDeps()`.
- `runAgentRepl(lines, rich, deps, metaprojectPort, sessionOpts?, initialPermissionMode?, slateSessionBox?, events?, configDir?, orient?)`
  — **not exported**, line 1432–2627 (its real closing brace is at 2625; the
  next thing in the file is the `TuiStartup` doc comment at 2627, then
  `resolveTuiStartup` at 2649). This is the readline "agent mode" REPL loop.
  **It already takes essentially the same injection shape as `runShell`** —
  every dependency the tests below want to observe (bus client, lease,
  jobRegistry, tools, slate box, reasoning override, configDir) arrives as a
  parameter or through `deps: AgentDeps`. The only thing stopping every
  "source-text audit" describe below from becoming a real behavioural test
  driven the same way `shell-bus.test.ts` already drives `runShell` is that
  **`runAgentRepl` has no `export` keyword**. This is the master seam for
  this file — flagged once here, referenced by short-hand ("export
  `runAgentRepl`") in the rows below instead of repeating it every time.
  A few real (non-injected) globals remain inside it even after exporting —
  `loadShellPermissions()` / `shellPermissionsFingerprint()` (real on-disk
  permissions file, no directory parameter) and TTY/`colorEnabled()` checks
  for the spinner — those would need their own follow-up seam if a test ever
  needs to control them, but none of the audits below touch that logic.
- `shellCommand(args, runtime: ShellCommandRuntime)` — **exported**, line
  3021–3919, the CLI entry point. `runtime` already injects `checkVersion`,
  `cacheDir`, `isTty`, `launchAgent`, `launchChat`, but NOT the dynamically
  `import()`-ed `refreshSavedGrants` (line 3127) or anything to observe call
  *order* against `chooseShellSurface` (line 3144). Inside it: the TUI branch
  `if (surface !== "readline")` at 3145–3704 (containing `makeAgentDeps` at
  3187), and the readline branch `if (agentMode)` at 3705–3919 (which
  declares `slateSessionBox`/`jobRegistry` and calls `runAgentRepl` at 3857).

A recurring, file-wide fragility that is NOT specific to any one audit below:
most `shell.test.ts`/`shell-bus.test.ts` describes compute
`replBody = shellSource.slice(indexOf("async function runAgentRepl("), indexOf("if (agentMode) {"))`.
`if (agentMode) {` is at line 3705, but `runAgentRepl`'s real closing brace is
at line 2625 — so `replBody` actually also contains `resolveTuiStartup`,
`parseShellCliFlags`, `chooseShellSurface`, and the entire TUI branch
(`makeAgentDeps` and everything in it) glued on after the real function ends.
Every `indexOf`/ordering assertion in these describes is silently relying on
none of their search literals accidentally recurring in that extra ~1100
lines of unrelated code. This is called out per-row below as "(wide
`replBody`)" rather than repeated in full each time. The one describe that
gets this right is flow 268 T26 (line 1696), which bounds `replBody` at the
`TuiStartup` doc-comment instead.
