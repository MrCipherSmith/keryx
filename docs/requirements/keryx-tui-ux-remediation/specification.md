## 2. Technical Architecture & Component Changes

### 2.1 ModalHost Isolation & Viewport Clamping (`src/tui/modal-host.ts`)

#### Defect Root Cause:
`ModalHost` mounts a container over the main pane with relative positioning. When drawing the modal box, cells outside the border in the host's bounding box are not cleared or filled with solid backdrop characters, allowing characters from previous transcript rows in columns 0..3 to remain visible in the terminal buffer. Furthermore, the modal width calculation `width = Math.min(viewport.width - 4, 100)` does not account for the sidebar offset on narrow/medium screens, bleeding into the vertical divider.

#### Architectural Fix:
1. **Backdrop Box Solid Fill:** Wrap the modal dialog in an explicit backdrop `BoxRenderable` spanning `left: 0, top: 0, width: mainWidth, height: mainHeight` with a semi-transparent or dimmed fill that clears underlying character cells.
2. **Strict Main-Pane Clamping:** Compute modal dimensions against `chrome.main.width` rather than `renderer.width`:
   ```ts
   const maxModalWidth = Math.min(mainWidth - 4, 104);
   const modalLeft = Math.max(2, Math.floor((mainWidth - maxModalWidth) / 2));
   ```
3. **Adaptive Height (`hug-content`):** Replace static height assignment with content-aware measurement:
   ```ts
   const contentRows = countRenderedRows(currentTabBody);
   const chromeRows = 4; // header, tab strip, divider, footer
   const calculatedHeight = Math.min(contentRows + chromeRows, Math.floor(mainHeight * 0.85));
   ```

### 2.2 Migration of `/model` and `/sessions` into `ModalHost` (`src/tui/tui-shell.ts`)

#### Defect Root Cause:
Currently, `selectProviderModelInTui` and `openSessionPicker` operate as legacy full-screen overlays. They invoke `renderer.clear()` or replace the root node, tearing down `ShellChrome` (header, sidebar, status bar). When dismissed, they trigger an expensive full re-render that risks losing cursor position and viewport scroll offset.

#### Architectural Fix:
Re-implement both pickers as standard `ModalHost` tabs:
1. **Model Picker (`/model`):**
   - Title: `Select Model`
   - Tab 1: `Models` (List of models filtered by configured provider)
   - Tab 2: `Providers` (Quick switch to another connected provider)
   - Body: `SelectRenderable` with inline filter input.
   - Preserves underlying shell chrome and dimmed backdrop.
2. **Sessions Picker (`/sessions`):**
   - Title: `Session Switcher`
   - Single-tab or dual-tab (`Current Project` / `All Projects`).
   - Clean tabular display of ID, title, timestamp, message count.
   - Deduped footer: `↑/↓ select · Enter open · Esc cancel`.

### 2.3 Transcript Scroll Management & Unread Stream Follower (`src/tui/shell-chrome.ts`, `src/tui/transcript-blocks.ts`)

#### Defect Root Cause:
1. In `src/tui/transcript-blocks.ts:1355`, `exit()` restores `scroll.scrollTop = savedScrollTop`. If an operator scrolled down to inspect recent blocks and pressed `Esc`, the viewport abruptly jumps back to the top.
2. When the user sends input while `scrollTop < maxScrollTop - 2`, `stickyScroll` remains `false`. Output generated by the agent renders off-screen with no visual indication.

#### Architectural Fix:
1. **Smart Exit in `createBlockNavController`:**
   ```ts
   const exit = (): void => {
     if (!active()) return;
     focusOwner = "composer";
     paintAll();
     // If user scrolled/focused a block near the bottom, stay at the bottom
     const nearBottom = scroll.scrollTop >= scroll.scrollHeight - scroll.height - 3;
     if (nearBottom) {
       scroll.stickyScroll = true;
     } else {
       scroll.stickyScroll = false;
       // Preserve user's deliberate scroll offset instead of force-resetting to savedScrollTop
     }
     focusComposer();
     onChange();
   };
   ```
2. **Auto-Follow on Turn Submission:**
   In `src/tui/shell-chrome.ts`, inside `submitComposer(text)`:
   ```ts
   chrome.scroll.scrollTop = chrome.scroll.scrollHeight;
   chrome.scroll.stickyScroll = true;
   hideNewOutputBadge();
   ```
3. **Unread Output Pill:**
   Add an ephemeral floating badge pinned above the composer:
   `[ ↓ New output below · Press G to jump ]`
   Rendered only when `stickyScroll === false` and `appendBlock` receives new tokens.

### 2.4 Layout & Typographic Hygiene (`src/tui/shell-chrome.ts`, `src/commands/agent-commands.ts`)

#### Defect Root Cause:
Terminal width constraints in narrow sidebars and modal tables cause unformatted line wrapping in the middle of words and URLs.

#### Architectural Fix:
1. **Hanging Indentation Formatter:**
   Create a pure helper `formatHangingIndent(prefix: string, text: string, maxWidth: number): string`:
   ```ts
   // Formats multi-line text where line 2+ aligns with text after prefix:
   // /goal    Deterministically start a goal — /goal <text>
   //          [--workspace <id>] [--auto [N]]
   ```
2. **URL Middle-Truncation in Tables (`/mcp`):**
   ```ts
   function truncateUrl(url: string, maxLen: number): string {
     if (url.length <= maxLen) return url;
     const front = Math.floor((maxLen - 3) * 0.6);
     const back = maxLen - 3 - front;
     return `${url.slice(0, front)}…${url.slice(-back)}`;
   }
   ```
3. **Dropdown Scrollbar Isolation:**
   Anchor the `/` command menu scrollbar strictly to its inner right edge, offsetting it by 1 column from the main pane edge so that it never shares a column with the transcript scrollbar.
