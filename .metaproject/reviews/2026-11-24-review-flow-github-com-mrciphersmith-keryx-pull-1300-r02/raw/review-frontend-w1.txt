### Findings

### [FE-R4-001] Flow-slot refocus flag stays armed after a failed Link
- Severity: info
- File: apps/desktop/src/review/PrWorkRow.tsx
- Rule: code-style-patterns (effect correctness / focus management); canonical rubric, law 1
- Problem: Link sets `refocusFlow.current = true`; it is cleared only when the offer disappears. When the write fails the offer stays (with its error), so the flag stays armed. If the offer is later removed by something other than the user (the session gets a Flow from another path, the flags dispatch from elsewhere), the effect calls `focus()` on the slot's button whenever activeElement is <body>, which it also is after a mouse click on any non-focusable area. focus() scrolls the element into view.
- Why it matters: a rare, unasked focus move and scroll of the board long after the failed press. No concrete trigger observed; reaching it needs a failed Link plus an external Flow link for the same session. Hence info.
- Fix: clear the flag when the offer settles with an error (e.g. in the effect: `if (offer?.error) refocusFlow.current = false;`), or arm it only for Dismiss and for Link's success path.

### [FE-R4-002] A successful Link whose flags dispatch is skipped shows "Create Flow" again
- Severity: info
- File: apps/desktop/src/session/useAcpSession.ts
- Rule: canonical rubric, law 1
- Problem: linkFlow dispatches the returned flags only `if (l.client === client)`. When the connection is replaced while the request is in flight but the request still resolves, accept() settles the offer to null, the slot falls back to "Create Flow" (and PrWorkRow moves focus to it) although the flag was written. It stays so until the sessions list is reloaded.
- Why it matters: pressing the focused "Create Flow" then would start a second Flow. Whether a request can resolve after its client is replaced was not checked; that, or a refreshSessions on reconnect, would settle it.
- Fix: on a skipped dispatch, trigger a sessions refresh (or keep the offer in `linking` until the session list carries the flow).
