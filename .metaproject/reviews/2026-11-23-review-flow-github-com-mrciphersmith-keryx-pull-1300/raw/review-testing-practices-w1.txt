  AC9's exec gate (`cd apps/desktop && bun test src`) therefore passes while "Create Flow" links nothing and does not prefill an existing bound session. - Rule: tdd-workflow.mdc, Review severities, "New or changed logic with no test … `major` where an acceptance criterion has no test". The App join is the only place AC9's chain composes, and no test reaches it.
- Fix: Extend the App fixture (`apps/desktop/src/test/app-navigation.fixture.tsx`) with one AC9 scenario in `ProjectNavigation.dom.test.tsx`:
