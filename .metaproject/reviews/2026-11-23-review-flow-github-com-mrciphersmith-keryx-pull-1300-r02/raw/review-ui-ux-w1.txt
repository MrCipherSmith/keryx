## Prior dispositions (checked against head 88e3faba9)

- UX-001: closed. styles/review.css now has `.pr-work-link:focus-visible, .pr-work-more:focus-visible { outline-offset: -2px; }`, so the ring is drawn inside the 24px buttons and the row's `overflow: hidden` no longer clips it. The Issue work row uses the same classes, so it is covered too. Ring contrast, computed from the tokens: light #2b8a71 is 3.73:1 on #edf2ef and 3.67:1 on #f9eedb; dark #8dc7ab is 9.68:1 on #0d1411 and 6.71:1 on #3a3020. All meet the 3:1 non-text floor. A Tab pass on a render was not run. The same fix also closes LY-003, which is review-layout's to record.
- UX-002: closed. PrWorkRow adds `is-attention` when `awaitingAnswer || publicationPending`, styled `color: var(--warn); background: var(--warn-soft); border-color: var(--warn)`. Text contrast is 5.25:1 (light) and 7.78:1 (dark), both above 4.5:1 for the 11px text. The text 'needs your answer' / 'publication pending' differs from the other states, so the cue does not rely on color alone. Hover (`.pr-work-link:hover:not(:disabled)`, specificity 0,3,0) replaces the tone with the hover look, which is acceptable. The fix introduced a scope regression, filed as UX-007.
- UX-003: open. IssueWorkRow.tsx still has ``const flowText = stage === "none" ? "Create Flow" : `Flow · ${STAGES[stage]}`;``, unlike the PR slot's `Flow #id · stage`.
- UX-004: open. IssuesBoard.tsx's list still has `<th>Keryx stage</th>` and renders the work row in the Actions cell.
- UX-005: open. PrWorkRow.tsx still has `disabled={!canReview}`, with the reason only in `title` ('Only an open pull request can be reviewed').

## What works (keep)

- Every card action has visible text, and its aria-label starts with that text ('Open on GitHub: PR #N', 'Subscribe: PR #N'), so WCAG 2.5.3 (label in name) holds.
- Quick filters are real toggles (`aria-pressed`). They appear in the active-filter chips (`filterSummary`) and the filter count, and 'Clear filters' or 'Reset search and filters' clears them. The empty state stays specific.
- 'Group by' is a labelled select, shown only on the board.
- Each lane has a text title, so the lane dots are not color-only. Lanes without a color rule (Draft, Closed, Others) use the neutral `--fg-subtle`.
- Work-row targets are 24px tall, which meets the WCAG 2.5.8 floor (24px).
- The session menu is portaled, so the card's paint containment cannot clip it. 'New session' is always the last menu item.
