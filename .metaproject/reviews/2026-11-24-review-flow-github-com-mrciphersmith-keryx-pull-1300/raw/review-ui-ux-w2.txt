## Findings

### [UX-017] A source chosen in another project turns off the fallback: a project without a GitHub.com remote is back to the error and a Retry that cannot work
- Severity: minor
- Criterion: Nielsen #9 (error recovery). State: error.
- File: apps/desktop/src/issues/IssuesBoard.dom.test.tsx (`localStorage.setItem(account + ".source", "repository");`)
- Evidence:
  - The new test "AC13 a repository source the person chose keeps Retry on a configuration error" pins this branch. It shows "configuration: This project has no GitHub.com fetch remote." with Retry and without "Show issues assigned to me".
  - In IssuesBoard.tsx, `chosen` is true whenever `stored(account + ".source")` holds any value. The `account` key is `[host, nodeId]` and does not include the project (the same key as UX-011).
  - So a choice made in one project counts as a choice in every project.
  - The docs and the plan describe the gate as "If you have not chosen a source yet" and "только пока источник не выбран пользователем". Neither says the choice may have been made in another project.
- Path:
  1. In project B, which has no GitHub.com remote, the user presses "Show issues assigned to me". This stores `assigned`.
  2. In project A, which has a remote, the user picks "Project repository" in Source. This stores `repository` with `chosen: true`.
  3. The user opens Issues in project B again.
  - Result: the error has no remedy, and Retry repeats a request that fails the same way every time. This is the UX-008 condition, now reached by a different route.
- Impact:
  - Trigger: a user with several projects who has ever picked Project repository explicitly.
  - Outcome: every project without a GitHub.com remote, and every repository with Issues off, shows the bare error and a Retry that cannot help. The user has to find the Source select on their own. No data is lost.
- Fix:
  - Store the source per project and account. That also fixes UX-011.
  - Or base the gate on the error's kind, not on `chosen`: for a configuration error, always offer "Show issues assigned to me" and drop Retry.
- Not observed on a render.
