### Clean areas (checked)
- Authz / gate bypass: the flow 460 (B) change lets a recorded `reviewer-override` decision account for missing reviewers with no dispatch `override` field. It is still bound to the package head (`decisionCovers`) and to every item in `reviewersLeftOut ∪ missing`, so a decision for another head or for a smaller left-out set counts for nothing. Trust is no weaker than before: on a gated package the decision file was already the only accepted record, and on an ungated one it replaces an agent-written dispatch quote.
- Path traversal: `save_result_to` confinement is unchanged, and the existing test still rejects `../`, symlinked dirs, `.env.local`, `.git/hooks` and empty values.
- Injection: the usage suffix is built with JSON.stringify from finite numbers and the provider/model id. The new test's git calls use Bun.spawnSync with argument arrays and no shell.
- Secrets: none. The test's noreply email is an existing fixture pattern also used in other test helpers.
- Schema: the `quote_unlocated` object has `additionalProperties: false`, an enum `reason` and integer `candidate_lines`. Ingest never relocates a quote by similarity, so no guessed anchor is accepted.
- Crypto, CSRF, open redirect, React/NestJS patterns: not present in this slice.
