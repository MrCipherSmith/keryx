## Summary

**Verdict on the `client.ts` grant check.** Weaker, but only by a margin that production does not reach. `verifyAuthorizationGrant` now lets `authorizedAt` lead the local clock by up to 250 ms. It still requires `expires > now`, `expires - issued <= LIMITS.grantMs` and the monotonic `elapsed < LIMITS.grantMs`, so neither deadline is extended (the PR's claim holds). `authorize()` already sleeps up to 500 ms for a future `authorizedAt` before verifying, and `valid()` runs later on the same wall clock. So the set of grants a machine accepts is the same on base and head, apart from sleep jitter or a backwards clock step. The 250 ms constant is therefore not the real bound (500 ms is); that mismatch is F-001. The new tests call the pure function and are red on base. The one test that goes through `authorize()` uses a 150 ms skew and passes on both, so the production path is untested for this change.

**Other slice-02 areas traced without a degradation:**
- Select chevron CSS. The new block sits in `@layer components`, in the same layer as `.hub-input`. `.hub-select:not([multiple]):not([size])` has higher specificity, so `padding-inline-end` and `background-image` win, and `.hub-input:disabled` still supplies the fill. No unlayered or utility rule on a `Select` consumer overrides the padding. `forced-colors` restores the native arrow.
- Rail collapse CSS. Rules are `min-width:1024px`-gated. The unlayered `max-width:1023px` and `767px` sidebar rules do not collide with them. `.identity`, its button and the nav buttons stay reachable. The accessible name now comes from `aria-label` and `title`, which match the old text.
- `css-rules.ts` parser. Comments are stripped, nested at-rules are tracked, and the data-URI chevron has no `;` or braces to confuse it.
- i18n. The 17 new `remote` keys and the 2 `workflow` keys exist in both locales. `launchHint` is still used through `remote:launchHint` in `workflow.tsx`.
- `session-timeline.ts` and its test. Placement is by history cursor, stable, and ignores clocks, and the tests would fail if clocks were compared.
- Composer header selector. It narrows from `.session-composer .hub-panel-header` to a child combinator, which is the intended change. A test pins it.
- Command search in `settings.tsx`. It keeps the selected entry in the options when the filter excludes it.
