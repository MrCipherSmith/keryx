The client bounded-clock-lead claim lives in slice-02 and was not assessed here.

**Paths traced and found correct.**
- Prepared draft: seeded with `prepared: true` and zero versions, un-prepared by the effect once `record.state !== "opening"`, `submit` and the Send button are both gated while opening, `stale` ignores empty/prepared drafts. The effect cannot loop because it exits when `prepared` is false, even though `useDraft`'s `setDraft` identity changes each render.
- Send success: `useDraft` returns the stored reference, so `current === submitted` is a real identity check; the draft keeps the Flow and blanks the text, and a mid-flight edit still routes to `draftPreserved`. Rejected receipts keep the text.
- Timeline: anchors are history cursors (record cursor or loaded pages, whichever is ahead); with ascending, paged history an outcome sits after all loaded messages at or below its anchor and later pages insert before it correctly. Equal anchors keep invoke order (stable sort). `Infinity - Infinity` in the comparator yields NaN, which sorts as equal.
- Outcome following: `useRemoteQuery` with a function `enabled` is supported by the pinned TanStack Query 5.105; invalidation skips a query whose function returns false, so settled outcomes stop refetching while the cached receipt stays. `Settings` calls `useAppliedReceipt` without `settled`, so its behaviour is unchanged.
- `Button` and `Input` ref forwarding relies on `ComponentPropsWithRef` plus React 19.3.1, which the app pins.
- Slash and Escape: `/` is taken only in an empty field with no modifier, no IME composition and no repeat; Escape hands the slash back only while `slashOpened` is untouched.
- i18n: every key used in this slice exists in the EN files read (remote, acceptance, context); `receiptStatuses.*` covers all `CommandOutcome.status` values.
- Empty and recovery states (`ProposalsView`, `DeliveryView`, `HistoryView` filter, `ReviewPresentation` gaps) behave correctly for the inputs that reach them; the gaps block deliberately ignores unresolved guides.
