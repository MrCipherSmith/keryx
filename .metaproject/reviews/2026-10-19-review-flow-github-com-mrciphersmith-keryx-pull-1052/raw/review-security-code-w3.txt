## Clean areas (checked, no finding)

- Press-field provenance: pressedBy/pressedAt are written only when ctx.confirmationVia === "remote" after the allowed-user check and the 1-hour TTL (operator-confirm-tools.ts invoke); no CLI path passes them; model input cannot reach them. tui-card records carry no press fields.
- complete-gated.ts: one function shared by `keryx review complete` (src/commands/review.ts runComplete) and the card; it adds run-profile and routing refusals on top of completeManagedReview, so the card gets the head gate, evidence level, READY readiness, research errors and waiver rules exactly as the CLI. The card never records a waiver itself; the CLI requires a TTY for --waive/--waive-coverage. Merged or moved PR handling is the shared gate-based behaviour (refused unless the report names the reviewed SHA and says the PR moved), not new.
- Unattended: "review_complete" is in OPERATOR_CONFIRM_TOOL_NAMES and isUnattendedExcludedTool checks both lists (src/trigger/unattended.ts), so an unattended run cannot call it.
- Remote client: askApproval returns deny with undelivered:true on every non-posted path (no stream, aborted, HTTP error, missing approvalId, throw); mapApprovalAnswer carries undelivered only when !yes; RemoteBridge.askApproval denies when there is no client or it is not connected; fromId is accepted only as a safe integer. No path turns a missing answer into allow.
- SKILL text (bundled review-orchestrator SKILL.md/SKILL.detail.md, review-premise SKILL.md): the lines "never run --mode automatic or --yes" and "never write an operator quote yourself; unattended, the item is Not run" are kept, the premise Iron Laws are unchanged, and the added review_complete and review_decide_premise card wording does not tell the agent to run or fabricate anything. Gap only: the text says nothing about what to do when a card is refused or undelivered (not filed; no attack vector).
- Other recorder changes (write-land.ts confirmation type, evidence-level.ts evidenceLevelLine with a non-global regex, help-groups.ts summary text): no injection, path or secret issue.
