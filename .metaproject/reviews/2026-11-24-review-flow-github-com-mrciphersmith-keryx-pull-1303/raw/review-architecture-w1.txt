### Summary
The PR adds two pure modules (`src/review/head-move.ts`, `src/review/update-round.ts`) and one optional field (`PublicationState.headMoved`). It threads a same-base/newer-head classification through `desk-publication.ts`. None of this invents a rounds schema. There is no store, migration, `review_id`/`round` column, or Review/Round type. `DeskRun` is unchanged, so it still matches spec:52 ("DeskRun becomes Attempt without format change"). `headMoved` lives in per-attempt publication state, so it stays a file in the Attempt directory as spec:76 requires. The new modules depend only on `type DeskRun` and `DESK_RUN_SCOPE` from `desk-run-types.ts`, which points inward. They attach to the planned Review/Round/Attempt model without a rewrite:
- `selectPriorAttempt(attempts)` takes the attempt format that spec:221 keeps as `Round.attempts: DeskRun[]`.
- `parseOnHeadMove` takes the nullable `reviews.on_head_move` column from spec:74.

There are two attachment points the next stage must handle deliberately. They are below as one minor finding and one info finding.
