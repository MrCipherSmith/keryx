### Summary
The fix round closes both logic majors. `moveTo` now focuses the target row's element directly, so Home on the first row or End on the last row leaves nothing pending. Status rows share the id `status:${parent}`, so a Retry or Show more updates the focused `<li>` in place. Snapshot mismatches now surface as `stale-snapshot` from `requestMetaprojectV2`, and the wiki group key is one exported helper.

One new minor defect comes from the focus hand-off that answered frontend-w1-F-001. The hand-off picks the replacement row by its old index. When answers for two folders commit together, focus can land on a row in another folder. Two info-level prior findings are still open: logic-w2-F-002 (the guide still promises an **Other** group) and ui-ux-w1-UX-005 (the counts still have no unit).
