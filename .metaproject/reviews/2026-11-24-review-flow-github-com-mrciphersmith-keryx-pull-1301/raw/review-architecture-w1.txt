### Summary
The fix round moves the wiki group-key rule into the shared contract module (`metaprojectWikiGroupKey`, `METAPROJECT_WIKI_UNTYPED_GROUP`) and uses it from both core (`wikiTree`) and Desktop (`revealSteps`). That direction is correct: the client depends on the contract, not the other way round. The snapshot-mismatch policy moves into the transport (`requestMetaprojectV2` now throws `stale-snapshot`), so every v2 caller gets the same typed error instead of the generic "Choose the bundled CLI" one. The leftover `negotiateMetaproject` wrapper is gone. The fix adds one new cross-layer coupling: the tree hook's `MAX_TREE_READS = 3` is sized against the Rust permit pool (`MAX_ACTIVE = 8`), and only a comment links them. It is reported as info. No blocker, major or minor findings.
