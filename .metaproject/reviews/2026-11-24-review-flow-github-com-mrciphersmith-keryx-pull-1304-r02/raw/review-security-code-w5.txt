### What was checked
- Argv injection, `include_closed` (Rust and dev shim). It is a typed `Option<bool>` in Rust and `=== true` in the dev shim. It appends only the literal `--include-closed`. Both bridges refuse it unless `reviews_only` is set, so no board, badge or paged query widens. `--repo` keeps its existing checks: not empty, no leading `-`, no whitespace. The CLI is spawned with argv, not a shell string.
- External link opening (T17, `ReviewBrowserLink` / `openReviewLink` / `ReviewPanel.openPullRequestLink`). `reviewUrl` admits only `https:` URLs with no userinfo. `openExternal` checks the `^https?://` scheme a second time and hands the URL to the Tauri opener plugin, or to `window.open(..., "noopener,noreferrer")`. `javascript:`, `file:` and custom-scheme URLs cannot reach the OS opener. The href shown on the anchor is the checked `href`. `onOpen` receives that value, not the raw `card.url`. Right-click (button > 1) is left to the default handler, and the app blocks in-webview navigation, per the comment and the stage-0 behavior.
- Focus hand-off across tabs (`ReviewsFocus.repo`, `focusRepo`). The repo comes from the Pull requests board's verified snapshot (`snapshot.repo`), not from GitHub content. It reaches the CLI only through `fetchReviews`, so it passes the same `--repo` validation.
- Review rules fallback (`rulesTarget` from the board identity). It applies only when the Reviews list failed with a non-access error. It also requires the board viewer to match `expectedViewer` and the board repo to match the selected repo. The target is the board's GitHub-verified identity, and the rules command scopes by it. No identity crosses accounts or repositories. The structural concerns about this fallback were already filed in waves 1-4 (review-style-w1 F-001/F-002, review-architecture-w1 F-003, review-frontend-w1 F-003, review-logic-w1 F-005). They are not re-filed here.
- Hidden-tab polling (`RUNNING_RELOAD_MS`, watcher poll reload). These are read-only `review reviews` calls through the existing read lane. They are skipped when the document is hidden. No mutation and no unbounded loop.
- XSS. No `dangerouslySetInnerHTML` or `eval` was added. The PR title, author and state labels render as React text. `DiscussionMarkdown` is unchanged in this delta.
- Secrets and PII: none in the code, comments or test literals.
