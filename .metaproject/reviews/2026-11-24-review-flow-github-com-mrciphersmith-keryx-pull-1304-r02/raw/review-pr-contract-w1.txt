### Findings

### [PC-001] PR body Store bullet still states the pre-D-R1 round rule

- **Severity**: minor
- **File**: src/review/desk-run-store.ts:103-115
- **Problem**: PR body, What changes → Store: "the same base..head joins its existing round as a retry; any other range opens the next round." The delta changed `roundFor` to D-R1: `const inTop = counted.filter(attempt => attempt.round === top); ... const retry = inTop.some(attempt => attempt.base === run.base && attempt.head === run.head); return { round: retry ? top : top + 1, previous };` and its doc comment says "an attempt repeating the current highest round's range is a retry in it; any other attempt, a return to an earlier range included, opens the next round". The body's own "Round rule" bullet in the fixes section says the opposite of the Store bullet, so the body contradicts itself.
- **Why it matters**: the Store bullet is the description a merger or stage-3 author reads for the rule; read alone, it says A,B,A puts the third attempt back in round 1, which the code no longer does.
- **Fix**: reword the Store bullet to "the same base..head as the current highest round joins it as a retry; any other range, including a return to an earlier one, opens the next round".

### [PC-002] desktop-app.md still sends the reader to a "Review" tab, now ambiguous with the new Reviews tab

- **Severity**: minor
- **File**: docs/docs/desktop-app.md:147
- **Problem**: PR body: "the tabs are now Sessions, Flows, Reviews, Pull requests, Issues, Metaproject" and "The Review rules button moved here". The fix for F-018 pointed Review rules at Reviews (desktop-app.md:157 "Open **Reviews → Review rules → New rule**") but left three lines naming a tab called "Review": :70 "## Find a pull request in Review", :72 "choose **Review** in its **Sessions / Flows / Review** navigation", :147 "From **Review**, open **PR watcher**". The "Review" wording was already stale on base (base AppShell.tsx:21 `label: "Pull requests"`), but before this PR no tab had a near-identical name.
- **Why it matters**: :147 and :157 sit ten lines apart; a reader told "From **Review**, open **PR watcher**" and then "Open **Reviews → Review rules**" goes to the Reviews tab for both and does not find the watcher there.
- **Fix**: say **Pull requests** at :70, :72 (navigation list Sessions / Flows / Reviews / Pull requests / Issues / Metaproject) and :147.
