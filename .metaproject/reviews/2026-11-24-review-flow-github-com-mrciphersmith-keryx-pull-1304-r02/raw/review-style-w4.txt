## Minor & Info

### [F-001] review-board.ts gives the shared JSON writers a second pair of names
- **Severity**: minor
- **File**: src/commands/review-board.ts:11
- **Problem**: `import { ..., writeBoundJson as writeJson, writeBoundJsonText as writeSerialized } from "../review/board-github"`. The fix moved the writers to board-github.ts under new names. review-reviews.ts:5 imports `writeBoundJson` under that name, but review-board.ts keeps the old local names as aliases (call sites :45, :64, :99, :103). The same binding-checked writer is now `writeJson` in one command and `writeBoundJson` in the other. The alias also drops "Bound", the part of the name that says the write is checked against the GitHub binding.
- **Why it matters**: The Name row covers one concept with two names. A search for `writeBoundJson` misses the four review-board call sites, and a reader of review-board.ts cannot see that its writes are binding-checked.
- **Fix**: Import `writeBoundJson` and `writeBoundJsonText` without aliases and rename the four call sites. review-reviews.ts already does this.
- **Patch**:
  ```diff
  - import { boardGh, boardGraphql, projectGithubConnection, reviewRepositories, selectRepository, writeBoundJson as writeJson, writeBoundJsonText as writeSerialized } from "../review/board-github";
  + import { boardGh, boardGraphql, projectGithubConnection, reviewRepositories, selectRepository, writeBoundJson, writeBoundJsonText } from "../review/board-github";
  ```
  (and `writeJson(` -> `writeBoundJson(`, `writeSerialized(` -> `writeBoundJsonText(` at :45, :64, :99, :103)
