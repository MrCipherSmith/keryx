## Summary
Slice-04 is mostly Desktop tests, fixtures and docs. In this lens, the backend code is two CLI command files.
- `src/commands/review-board.ts` moves the pipe writer (`writeJson`/`writeSerialized`) into `src/review/board-github.ts` as `writeBoundJson`/`writeBoundJsonText`.
- `src/commands/review-reviews.ts` adds `--include-closed`, batches the card reads, and gives the comparison phase an overall deadline.

The move keeps the account-binding check at the publication boundary: `writeBoundJsonText` still wraps the stdout write in `withCurrentGithubBinding` (board-github.ts:109-112). No caller still imports `writeJson` from review-board; a test asserts that (export-check test, lines 327-328).

The new `compareHeads` deadline is sound:
- The timer is cleared in `finally`.
- A compare that rejects after the race has already settled on "late" is handled by the race's own subscription, so it raises no unhandled rejection.
- Failed and late comparisons each add one warning and leave the commit count unknown.

`--include-closed` is a strict boolean in `parseArgs`, and the usage string and cli-reference.md both document it. I found no blocker, major, minor or info in this lens.
