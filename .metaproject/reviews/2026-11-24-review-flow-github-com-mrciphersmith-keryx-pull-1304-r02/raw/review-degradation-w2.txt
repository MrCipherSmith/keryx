## Findings

### [F-001] PR panel offers "Open in Reviews" for a PR whose only runs were superseded before they started, but the Reviews list no longer lists that Review
- Severity: minor
- Class: behaviour-delta
- Evidence kind: consumer-trace
- File: apps/desktop/src/review/ReviewDetail.tsx:177 (`const hasReview = local.runs.length > 0;`)
- Problem: Two changes in this delta disagree about what counts as a Review. Head reviewRows (desk-run-store.ts:606) now drops never-started superseded rows (`AND NOT ${neverStarted("r.")}`). On the delta base those rows were listed. The PR panel's run read is the status history (desk-run-store.ts:445-456). It filters only `decision.action != 'delete'`, so it still returns those rows. `hasReview` is now `local.runs.length > 0` (the FB-5 change, which counts archived runs on purpose). Take a PR whose only remaining runs are queued requests superseded before they started, for example after the run that superseded them was deleted. The PR panel then shows "Open in Reviews" in place of the Start/New review round button (ReviewDetail.tsx:251). The Reviews tab cannot find the Review. It re-reads once, then shows "Pull request #N has no Keryx review in this list." (ReviewsView.tsx:244-249). On the delta base, the same PR was listed in Reviews (never-started rows were not excluded), so "Open in Reviews" found it.
- Why it matters: In this state the PR panel's header action leads to a dead end, and the panel no longer offers a start. The board card's own review action still starts a review through the start intent, so the user is not blocked. Rare trigger.
- Fix: Give `hasReview` the same predicate as reviewRows. Count a run only if it is not a superseded-before-start request (state `skipped`, phase `Superseded`, no startedAt, result or usage). Better, export one predicate the store and Desktop share. Add a ReviewDetail DOM case with a single superseded-never-started run.
- Evidence: consumer-trace. Read the delta diff of desk-run-store.ts: base reviewRows `NOT IN ('archive','delete')` became head `!='delete' AND NOT ${neverStarted("r.")}`. Read desk-run-store.ts:445-456: history `scoped` filters only `!='delete'`. Read ReviewDetail.tsx:174-177 and 251. Read ReviewsView.tsx:225-251, the focus path to the "no Keryx review" notice. Refute: FB-5 settles counting archived runs, which the Reviews list now shows under Show closed. It says nothing about never-started rows, and the neverStarted exclusion (FA-11) was added to reviewRows only. Base `hasReview = runs.some(run => !reviewIsArchived(run))` also counted never-started rows, but on base the list held them, so the hand-off worked. The trigger needs every non-deleted run of the PR to be never-started. I did not check whether `delete` is allowed on the superseding run in every state, so the frequency is unverified.
