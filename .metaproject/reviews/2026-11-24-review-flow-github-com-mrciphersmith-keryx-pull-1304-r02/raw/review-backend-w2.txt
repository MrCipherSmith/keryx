## Minor & Info

### [R2-BE-W2-001] `board_read_args` now takes two adjacent positional bools, `reviews_only, include_closed`
- **Severity**: info
- **File**: apps/desktop/src-tauri/src/review.rs:51-52
- **Problem**: The function takes nine positional parameters under `#[allow(clippy::too_many_arguments)]`, and four of them are bare `bool`s (`repositories_only`, `paged`, `reviews_only`, `include_closed`). The new `include_closed` sits right after `reviews_only`, so a swapped call such as `(…, true, false)` compiles. The unit tests call `board_read_args` directly, so they would not catch a swap at the single production call site (`review_board`, :141). In practice a swap fails closed: `reviews_only=false, include_closed=true` returns the configuration error. That is why this is info and not minor.
- **Fix**: Optional. Pass a small options struct, for example `BoardRead { reviews_only, include_closed, paged, repositories_only }`, or an enum `ReadKind::Reviews { include_closed } | Board { paged, … } | Badges(…)`. Either makes the mutually exclusive modes unrepresentable instead of checked at runtime.
