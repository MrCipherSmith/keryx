- **Severity**: minor
- **File**: .metaproject/flows/519-2026-11-24-desktop-review-v2-stage2/plan.md:59
- **Problem**: PR body: "Open in Reviews: it now carries the repository, so it opens the right Review in multi-repo projects" and "Indicator freshness: the indicator stays current while the tab is hidden." The delta edited plan.md's T5, T6 and T7 (toolbar) text to match the fixes, but T7 still says (plan.md:59) "App holds `reviewsFocus {number, nonce}`; the PR board gets one new optional prop `onOpenInReviews(number)`" and (plan.md:60) "it reloads on mount, on Refresh, on tab activation and every 60 s while the tab is active". Head: ReviewsView.tsx:26 `export interface ReviewsFocus { repo: string; repositoryId?: string | undefined; number: number; nonce: number; intent?: ReviewIntent | undefined }`; ReviewsView.tsx:194 the 60 s timer runs whenever a Review is running and skips only `document.visibilityState === "hidden"`; :198 reloads on `subscribeSessionReview`; plus the PR watcher `reloadSignal` (FB-4).
- **Why it matters**: the PR body names the flow package (plan) as the source for the design; a stage-1/stage-3 author reading T7 rebuilds the number-only focus (the round-1 multi-repo major) or the active-only reload (the round-1 hidden-indicator major).
- **Fix**: update plan.md T7's Cross-tab and Indicator bullets: focus `{repo, repositoryId?, number, intent?, nonce}`, consumed once (`onFocusHandled(nonce)`); reload also on session-review events and watcher polls, 60 s timer while queued/running unless the window is hidden (fix round 1, FB-1/FB-3/FB-4).
