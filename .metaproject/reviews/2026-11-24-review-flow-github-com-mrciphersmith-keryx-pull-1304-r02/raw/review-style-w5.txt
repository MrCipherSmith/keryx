## Minor & Info

### [F-001] `neverStarted` names its table-alias parameter `r`; the sibling helper in the same file calls it `alias`
- **Severity**: minor
- **File**: src/review/desk-run-store.ts:27
- **Problem**: `const neverStarted = (r = "") => \`(${r}state='skipped' AND …${r}details…\`` takes a SQL table-alias prefix as a single-letter parameter. One call site passes `"r."` (line 606), so `r` names both the parameter and the SQL alias that is passed into it. In the same class, `placement(alias = "")` (line 174) takes the same kind of value and calls it `alias`.
- **Why it matters**: A reader has to work out from the template body that `r` is an alias prefix. Here one concept has two names (`r` and `alias`), and the Name row says single-letter names are only for loop counters and short callbacks.
- **Fix**: Rename the parameter to `alias`, to match `placement`: `const neverStarted = (alias = "") => …`.

### [F-002] `stateAttempts` and `stateAttempt` differ by one letter and return different things
- **Severity**: minor
- **File**: src/review/review-entity.ts:132
- **Problem**: `stateAttempts(row)` (line 132) returns the attempts that are used for state, findings and publication: the unarchived ones, or all of them when every one is archived. `stateAttempt(attempts)` (line 145) picks the single attempt that the state comes from, and it does not always pick the latest one. `summarizeReview` calls them on consecutive lines (`const attempts = stateAttempts(row); … const settled = stateAttempt(attempts);`). The result of `stateAttempt` is stored as `settled`, which is a third name for it.
- **Why it matters**: A one-letter difference between two different concepts is easy to misread and to autocomplete wrongly. A reader of `summarizeReview` has to open both helpers to tell them apart. This is the Name row ("needs a comment / gives one concept two names").
- **Fix**: Name each helper after what it selects. For example, `countedAttempts(row)` (or `unarchivedOrAll`) for the set, and `stateSource(attempts)` (or `settledAttempt`) for the single attempt. If you use `settledAttempt`, the local `settled` matches the helper's name.
