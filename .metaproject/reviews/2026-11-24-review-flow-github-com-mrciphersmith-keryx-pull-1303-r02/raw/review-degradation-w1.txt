### [F-001] A superseded round can now be published as is from History, after a newer round of the same Review

- **Severity**: minor
- **Class**: behaviour-delta
- **Evidence kind**: base-diff
- **File**: apps/desktop/src/review/ReviewRuns.tsx:105
- **Problem**: On base, `prepare` blocked every attempt whose head was not the PR head (`!current ? "The pull request is closed or its revision moved..."`, base desk-publication.ts:242), so an earlier round opened from History could only be saved locally. On head the block is `!current && !headMoved` (desk-publication.ts:312), and `headMoved` is set for any attempt whose reviewed head is an ancestor of the PR head (desk-publication.ts:387). `RunAttempt` offers "Publish to GitHub" for historic attempts too (`draft` at ReviewRuns.tsx:105 does not check `historic`). So round 1 on commit A, opened from History while round 2 on the current head B exists (possibly already published), now gets an enabled "Publish as is for A" that posts a Comment for A after B's review. The dialog's primary action, "Update review to B", does nothing for that attempt except close both dialogs (ReviewWorkspace.tsx:128 returns when `action.open`); the test "Update review from an earlier attempt does not start a second attempt" pins that no-op as intended.
- **Why it matters**: A user browsing History can post an older, superseded round to GitHub after the newer round. The dialog names both commits, so the result is not hidden, but the outcome (an out-of-order review comment on the PR) was impossible on base. The spec section "Перед публикацией" offers as-is publishing when the head moved after the round finished; it does not say whether a round that a later round has superseded should still offer it.
- **Fix**: Either offer the as-is variant only for the newest round of the Review (pass `historic`/"superseded" into the dialog and fall back to the base refusal), or keep it and record the decision in the PR's "Decisions taken" list. If kept, consider not showing "Update review" as the primary action for an attempt whose successor round already exists.
