### Findings

#### [F-001] More agent-facing "run `keryx review complete`" wording contradicts the card-only completion rule
- Severity: minor
- File: src/gdskills/bundled/skills/review/review-orchestrator/SKILL.md:134 (also :124, Round plan step 9) and SKILL.detail.md:866; the same text is mirrored in .metaproject/skills/gdskills/review/review-orchestrator/
- Problem: The diff introduces the rule that an agent completes a round only through the review_complete card, with completion going through completeReviewGated. These sites still tell the agent that `keryx review complete` is the tail it runs ("every managed round finishes them. The verdict is interim: the round is not done until `complete`"; "A refused `review complete` names what is missing: fix that with a command and run it again"; Round plan step 9 lists `complete`). These are sites beyond the known SKILL.md:782 / SKILL.detail.md:386.
- Impact: The skill is the contract the orchestrating agent follows. Contradicting instructions send it down the terminal path that the new gate treats as non-card, or leave it stuck when it cannot run the command.
- Fix: Reword each site card-first: complete by raising the review_complete card; mention the CLI only as the operator's terminal fallback. Update the bundled copy and the .metaproject mirror together.
- Confidence: medium (wording only, no runtime effect)

#### [F-002] Press-provenance shape is re-declared in several modules
- Severity: info
- File: src/review/types.ts (CardPress, cardPressFields); parallel inline shapes in src/flow/confirm-token.ts, src/flow/service.ts, src/flow/types.ts, src/learning/decisions.ts, src/harness/external/write-land.ts, src/harness/tool/builtin/interactive-tools.ts
- Problem: Only the review layer has the shared helper that spreads pressedBy / pressedAt only when the source is a remote card. Other modules repeat the optional fields and the conditional spread, and validation differs (coverage-complete validates pressedBy; others do not).
- Impact: The invariant "provenance only with remote-card" is enforced per module, so a later change can drift. No current defect was found in the diff.
- Fix: If the shape is wanted outside review, move CardPress / cardPressFields to a neutral leaf shared by flow, learning, harness and review. Not required for this PR.
- Confidence: low (opinion, no named violation)
