### [R-001] Orchestrator skill still tells the shell agent to run `keryx review complete` after a waiver card

- **Severity**: major
- **File**: .metaproject/skills/gdskills/review/review-orchestrator/SKILL.md:782
- **Problem**: The PR sets the rule that an agent never runs `keryx review complete` and closes through the review_complete card (SKILL.md line 47 and line 136, completion-gate.ts nextStep, TM-04). Two instructions in the same skill, which the PR edits and which the agent reads while orchestrating, still say the opposite for the waiver paths: SKILL.md:782 "in keryx shell call `review_waive_coverage` (a card, never a terminal), then run `keryx review complete`" and SKILL.detail.md:386 "in keryx shell call `review_waive_readiness` (the operator answers a card, never a terminal), then run `keryx review complete <package>`". Both lines predate the base (git blame: commit 0f70964c, an ancestor of 062aa9c3), and were correct before this PR; the change to the close path (review_complete card, nextStep wording, the "agent never runs it" rule in SKILL.md:136) is what makes them wrong. The bundled mirrors under src/gdskills/bundled/skills/review/review-orchestrator/ carry the same two lines.
- **Why it matters**: After a coverage or readiness waiver (and the memory-outside-stage repair path), the agent follows the skill and runs plain `keryx review complete <package>` through shell_exec. Plain complete has no TTY check and no command-risk floor (only --waive and --waive-coverage do; TM-04 section 8), so the round can reach `closed` with no review_complete card, no operator press, no confirmedVia and no pressedBy. The head, evidence, routing and readiness gates still apply; what is bypassed is the operator's final yes and its press record. This is the skill-text half of D-01: the tool strings are fixed, the instruction file the agent reads first is not, and the D-01 enumeration that said the skills "already say call the review_complete card" missed these two lines.
- **Fix**: In SKILL.md:782 and SKILL.detail.md:386 (and both bundled mirrors) replace ", then run `keryx review complete`" / ", then run `keryx review complete <package>`" with ", then call the `review_complete` card". Keep the "elsewhere the operator runs ..." part as is.
