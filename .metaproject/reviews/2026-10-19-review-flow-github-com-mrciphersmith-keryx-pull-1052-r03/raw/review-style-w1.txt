## Minor & Info

### [F-001] Skill and guide text says an agent never runs `keryx review complete`, but the autonomous profile prompt and the exit table still direct it to

- **Severity**: minor
- **File**: src/gdskills/bundled/skills/review/review-orchestrator/SKILL.md:136
- **Problem**: The text now states "an agent never runs `keryx review complete`; that command is for a human in a terminal". The same wording is at `.metaproject/skills/gdskills/review/review-orchestrator/SKILL.md:136`, SKILL.detail.md:669 and `docs/docs/guides/autonomous-review.md:35`. In the same tree, `src/review/autonomous-profile.ts:144,153` still prompts the autonomous agent to run `keryx review complete`, and the guide's exit-code table (row 0) says "closed by `keryx review complete`". Unattended runs do not get the card tools, so they have no other way to close.
- **Why it matters**: Convention consistency and reader trust. A skill, a guide and a prompt that disagree on one command is the same contradiction C-21 was raised for; the text moved but the disagreement remained. An agent reading the skill and the profile prompt gets two instructions.
- **Fix**: Make the skill and guide wording conditional on the run mode: "in an attended shell, close through the `review_complete` card; an unattended run closes with `keryx review complete`". Or update the autonomous prompt and the exit-table row to match the new rule. Either way, one statement of the rule, referenced from the other sites.
- **Evidence**: `src/review/autonomous-profile.ts:144,153` (prompt text); `src/trigger/unattended.ts:55-83` (card tools excluded from unattended runs, including `review_complete`); the four sites above.
- **Confidence**: medium
