Three non-blocking concerns: the 25-compare cap always picks the same highest-numbered PRs, so "Refresh to read more" never reads more; card reads cover every stored Review (closed PRs included) in sequential 20-PR GraphQL batches on every poll; and there is no overall deadline, so a stalled GitHub can push the call past the Desktop's 150 s kill instead of degrading.
