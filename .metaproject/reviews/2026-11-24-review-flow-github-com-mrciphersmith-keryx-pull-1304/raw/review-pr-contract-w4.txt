- **Severity**: minor
- **File**: docs/requirements/keryx-desktop-review-v2/implementation-plan.md:29
- **Problem**: The PR body's Sources line reads "PRD R8, rest of R4, R12". PRD R4 (prd.md:40) asks the PR card and panel to show a review link with "состояние и номер раунда". The plan's stage table is unchanged context in this diff. Its row 2 (implementation-plan.md:12) has stage 2 deliver "Ссылка ревью на карточке PR с раундом и отставанием". The hand-off (line 67) says stage 2 "добавляет к ссылке раунд и отставание". The diff does neither:
  - The PR panel gets a bare "Open in Reviews" button, with no state and no round (ReviewDetail.tsx, `hasReview && onOpenInReviews ? <button ...>Open in Reviews</button>`).
  - The card only puts `outdated.round` into the outdated action's title, and only for a stale result.
  - `LocalBadge` has no behind or commit-count field (`keryx ctx rg "behind|commits"` in board-badges.ts and board-types.ts finds nothing).

  The flow's own description.md:21 defers the work row and its review link to stage 1 (PR #1300). But the "Состояние этапа 2" section that this diff adds lists the filters it did not build, not this. The PR body likewise names only the filters under "Not verified".

The stage 1 overlap note covers only the round of an outdated result, so even after both PRs merge the behind count has no source on the card.
- **Fix**:
  - Either add a line to "Состояние этапа 2" and to the PR body's "Not verified / not built" list: the PR-card and panel review link with state, round and behind (R4 remainder) is not in this stage.
