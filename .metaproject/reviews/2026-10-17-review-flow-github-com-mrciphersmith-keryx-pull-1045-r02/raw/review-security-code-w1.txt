### Findings
- SEC-R2-001 (minor), src/review/completion-gate.ts namedBySession: a package whose manifest reviewId is a command word (`keryx`, `review`) counts as named by every keryx review command. A package committed in the reviewed PR can redirect the nudge when no fresh pointer exists.
- SEC-R2-002 (minor), src/review/completion-gate.ts:324: the PR can commit a closed review-flow manifest under cwd. If it is checked out mid-session, it releases the gate before a package is opened, or when the chosen package is older. This is what remains of round-1 SEC-002.

- Path traversal: session roots must be inside cwd (`inside`). save_result_to goes through resolveSaveResultPath, and an empty or partial result never overwrites a non-empty file.
- Prompt injection into nudges: displayId sanitises ids, and nudgeLine flattens and bounds blockers.
- Secrets/crypto: none in the slice.
