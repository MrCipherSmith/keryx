## Findings (all minor or info; no blocker, no major)

### [F-001] RetainedView test cannot tell "active" from "visible"
- Severity: minor. File: apps/desktop/src/App.dom.test.tsx. Mutant A1 (`hidden={!visible}` -> `hidden={!active}` in App.tsx `RetainedView`): 1/1 green.
- Problem: the test drives both props from one value, `root.render(React.createElement(RetainedView, { active, visible: active, children: React.createElement(Draft) }))`, so no fixture builds the input that separates the two. App.tsx:594 passes different values (`active={workView === "metaproject"}`, `visible={view === "metaproject"}`): the case that matters is Settings open over the work view (active true, visible false). The component has no other test, and App.tsx wiring is not tested at all.
- Why it matters: the gate was added so the explorer stays mounted but hidden; swapping to `active` would show it over Settings, with the suite green.
- Fix: render with `{ active: true, visible: false }` and assert the wrapper is `hidden` while the input is kept; and `{ active: false, visible: false }` before the first visit asserts nothing is mounted.

### [F-002] "a zero-sized container is never fitted" asserts only a falsy state; the fit and zoom success paths never run
- Severity: minor. File: apps/desktop/src/metaproject/RelationshipGraph.dom.test.tsx. Mutants G5 (drop `if (!target.usable) return;`) green; G9 (drop the 0.3 .. 2.5 clamp) green; G6 (drop the `clientWidth` guard in `zoomBy`) red.
- Problem: in happy-dom `clientWidth` is always 0, so the test compares `zoom()` before and after and gets 1 either way; `computeViewport` returns zoom 1 for a zero box, so removing the `usable` gate leaves it green. No test gives the container a size, so `cy.viewport({ zoom, pan })` and the zoom clamp are never exercised (AC5 measures this live only).
- Why it matters: "no positive artifact that the path ran" (skill row 4): the test passes when `fit` does nothing at all.
- Fix: stub `clientWidth/clientHeight` (as the NodeDetailsPanel test already does for `host`) on the viewport element, assert `zoom()` and `pan()` after Fit and after repeated Zoom in beyond 2.5; keep the zero-size case as the negative half.

### [F-003] RelationshipGraph: theme attributes, hover and style classes unpinned
