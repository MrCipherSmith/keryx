### Comparison Notes

- Existing accepted wiki documentation and the prior source-grounded investigation
  reduced code rereads while preserving traceability.
- The gdgraph snapshot reported that the repository moved since its build, so it
  was used only for navigation, not as proof.
- A machine-readable report schema was added after adversarial review found that
  the specification defined persisted JSON without a schema.
- No subagents were used, so all package consistency stayed in one context at the
  cost of a larger primary-agent document workload.
- The known defect in `memory search` rewrote tracked legacy artifacts even during
  requirements gathering, directly reproducing the PRD's primary problem.

### Metric Reliability

- Exact/counted: tool calls, shell commands, subagents, changed-file count,
  package line count, tracked docs numstat, checks, and command list.
- Estimated: start time, wall time, and unique files read because the runtime did
  not expose a complete run event ledger.
- Unknown: token counts and exact runtime model identifier because the host did
  not expose them.
