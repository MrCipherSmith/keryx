# Acceptance Criteria

- AC1: **AC-04**: Сохранены до/после inventory и advisory paths; каждая группа проходит packaging и regression; major incompatibility имеет явный миграционный шаг, функции не исчезают ради счётчика.
- AC2: **AC-24**: До пилота заданы сценарий, самостоятельное подключение, полезность, повторное использование; участники и разрешение контакта определяются отдельно.
- AC3: **AC-M11**: Проверка claims inventory не приписывает README отсутствующую цитату; каждое сравнение имеет воспроизводимую разрешённую ссылку либо помечено гипотезой.
- AC4: Current focused/type/build/health checks and independent review have explicit evidence; prerequisites are satisfied; no required failed/incomplete check is relabeled PASS; partial acceptance is not full phase completion.
