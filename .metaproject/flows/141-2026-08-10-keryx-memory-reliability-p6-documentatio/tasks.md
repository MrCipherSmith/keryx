# Tasks

Task definitions live here; task **statuses** live in flow.json and are managed
only via `keryx flow task done <id> <taskId>`.

| ID | Kind | Title |
|----|------|-------|
| T1 | context | Collect and reconcile P0–P5 context, code graph, wiki, and package status |
| T2 | implement | Implement P6 documentation, metadata, migration, and wiki updates |
| T3 | test | Run targeted/full verification and record exact evidence |
| T4 | review | Perform structural/adversarial review and prepare verified handoff (no PR) |
