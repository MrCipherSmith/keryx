| Area | Equivalent behavior / meaningful difference | Recommendation |

| Snapshot races | Ours `cache.shareWorkSnapshot` protects the latest cache value at TanStack cache commit via `structuralSharing`; remote `loadWorkSnapshot/workSnapshotQuery` merges current cache after the network read. Both explicitly handle the reviewed slow-refetch race; remote shares query construction. Ours retains existing identities for equal versions; remote starts from the fresh cut and overlays newer cached records. | Keep ours and its actual live race tests; remote helper is an optional later simplification, not a required safeguard. |
| Refresh/resync edge paths | Ours `requestWorkRefresh` has an exact active-snapshot fallback when no event listener exists; remote `requestWorkPoll` wakes registered listeners only. Ours immediately invalidates exact Attention on own receipt; remote waits for the woken event result. On no-snapshot retention resync, ours also invalidates active observations; remote only replaces Attention. Ours allows a requested wake through hidden-tab throttling; remote always defers hidden tabs. Neither refreshes immutable document queries broadly. | Keep ours' fallback and related-query safeguards. Remote's normal active-board path is otherwise equivalent. |
| Evidence Attention | Both adapters accept Evidence. Remote board resolves it only from a cached Attempt, labels Evidence by UUID, and omits it if that parent is missing. | Amendments | Both include live unapproved new Intents, exclude cancelled ones from replacements, and use all manifest Intents for resolution CAS. Ours `src/hub/domain.ts:hubRead` implements that; remote returns the full revision for that URL. Mixing ours UI with remote backend silently fetches full trees for metadata. Retain ours exact-summary route, or deliberately adopt remote's direct-ID detail/line-invariant approach together with corresponding UI tests.

Tests worth retaining: ours `work-live-attention.case.tsx` (Evidence-only Overview/click/failure), `work-live-updates.case.tsx` (no-owner bounded resync, race and receipt-only side effects), `work-live-choices.case.tsx` (subject,criterion,context), `work-live-amendments.case.tsx` (manifest versions and Flow-only live command boundary), `revision-pagination.case.tsx` (57rows/exact selected line).
