# Metaproject Graph and Wiki in Keryx Desktop

A Desktop project window needs to browse its Metaproject without switching to a terminal. Add a Metaproject view with shared search and selection across a code-and-wiki graph and a Markdown reader. Selecting a page, module, file or indexed symbol must make its verifiable connections visible and navigable. Views must remain useful offline and when an optional index is missing.

This Flow covers project-local reads, relationship navigation, Git/worktree isolation, and native verification. Wiki authoring, external indexing services and automatic indexing of other repositories are separate work.
