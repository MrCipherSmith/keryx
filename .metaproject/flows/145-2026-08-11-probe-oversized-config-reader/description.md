# Стабилизировать probe oversized config reader

CI не должен ждать 60 секунд, когда дочерний Bun process аварийно завершается или зависает на намеренно oversized config file. Исправление сохраняет смысл теста: raw reader обязан завершаться неуспешно, а harness обязан наблюдать это за собственный короткий deadline.
