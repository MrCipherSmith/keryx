## Comparison Notes

- Sol on architecture, implementation, and strict review found and resolved
  concurrency and late-render defects that a mechanical model was not assigned.
- Luna efficiently handled bounded RED tests, context inventory, and public
  documentation.
- The existing graph was reported stale after repository movement, so workers
  verified graph-selected claims against source.
- The first changed test run exposed macOS `/var` canonicalization noise; using
  canonical `/private/tmp` produced a clean 347/347 report without code changes.
- The user's root-owned npm cache caused one pack retry; an isolated temporary
  npm cache produced a successful dry-run package.
- Three adversarial Sol passes found independent cache reconciliation and TUI
  display bounds; all were fixed before merge and re-reviewed at exact HEAD.
- A failed exact-HEAD CI run was retried once after its unchanged 3 GiB abort
  probe timed out; the retry and both later exact-HEAD runs passed.
- The release bump exposed a test that hard-coded `0.2.18` as the future
  registry version. The test now injects stable current/latest fixtures, so
  future version bumps do not invalidate the behavior assertion.
- Local macOS `/var` versus `/private/var` identity mismatch is a pre-existing
  follow-up, not a PR #262 regression. Canonical `/private/tmp` proved the
  affected serve suite 42/42; clean GitHub CI and the tag workflow passed.
