# Desktop Settings, theme palettes and project GitHub accounts

Keryx Desktop users need a navigable Settings screen and a separate GitHub sign-in for each project. The current screen has no close button inside a project and custom palettes force dark mode.

A user can close Settings back to the active project view, find Appearance, Sessions, Integrations and Desktop as tabs, connect multiple GitHub accounts, choose an account on opening an unconfigured GitHub project, change it in Project Settings, and see it in Activity. The user can select and retain independent light and dark palettes.

Scope is GitHub.com through GitHub CLI and local Review, including PR polling and fetching. Ordinary Git author identity and user Git actions follow the user's Git configuration.
