# Acceptance Criteria

После freeze менять критерии только через flow ac update; подтверждать только по доказательствам.

## Criteria

- AC1: При route on, конкретном доступном назначении quick и отсутствии ручного /model приветствие использует назначенную модель, показывает маршрут и увеличивает routed; ручная фиксация, блокировка external и fallback показывают причину без обхода запретов; сценарии проверены автоматически и в runtime оператора. [verify: judged]
- AC2: Последнее сообщение Main queue обрабатывается ровно один раз в FIFO-порядке, включая поступление на границе завершения хода; автоматическая регрессия и ручная очередь из трёх сообщений подтверждают отсутствие пропуска/дублирования; Edit/Delete/Force и Side-1 не регрессируют. [verify: judged]
- AC3: Неизвестная slash-команда показывает раскрываемую справку с 5–8 командами в свёрнутом виде и полным актуальным списком после раскрытия; UI-тест и ручная проверка подтверждают оба состояния. [verify: judged]
- AC4: /tasks доступна в реально запускаемом shell оператора: список/статус, чтение вывода и остановка тестовой задачи с подтверждённым killed; справка и документация согласованы с runtime, есть автоматическая регрессия командного пути. [verify: judged]
- AC5: Read-only подагент показывает состояние запуска до первого ожидания модели; отчёт содержит не менее трёх сравнимых запусков до/после с runtime/model и временем до статуса/начала работы; доказанные лишние ожидания устранены и защищены тестами, медиана локальной задержки снижена, сетевое ожидание показано отдельно. [verify: judged]
- AC6: Для короткого запроса на одинаковой истории/модели отчёт до/после показывает состав входа (инструкции, история, инструменты), total/cached/uncached либо явное отсутствие данных провайдера; входная нагрузка снижена измеримо без потери INTERRUPT-ALPHA и пожелания о справке после compact/restore; счётчик не выдаёт total за полную стоимость и покрыт тестами. [verify: judged]
- AC7: Отказ в shell_exec не выполняет команду и не обходится; routing не включает external автоматически; compact/restore сохраняет контрольные факты, связанные автоматические тесты и проектные проверки проходят. [verify: judged]
- AC8: Журнал docs/verification/shell-smoke-2026-10-05.md содержит для всех шести замечаний установленную причину или доказанное отличие runtime, изменение, результаты регрессии и ручное доказательство закрытия; оператор подтверждает удобство после повторного smoke-теста. [verify: judged]
