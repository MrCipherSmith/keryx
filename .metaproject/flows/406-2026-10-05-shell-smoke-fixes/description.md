# Shell smoke findings: reliable routing, queue and convenient UX

Status: formalized
Source: human request; docs/verification/shell-smoke-2026-10-05.md

## Problem

Шесть замечаний smoke-теста: routing без метки/роста счётчика, возможный пропуск последнего сообщения Main queue, громоздкая slash-справка, отсутствие /tasks в runtime оператора, медленный старт подагента и непрозрачный расход токенов. Причины пока не доказаны.

## Expected Outcome

Замечания исправлены и защищены регрессиями; работать удобнее: сообщения не теряются, маршрут или причина пропуска видны, справка компактна, задачи доступны, старт подагента прозрачен, входная нагрузка снижена без потери контекста и защит. «Больше не возвращаемся» означает закрытие конкретных сценариев с регрессиями, не гарантию отсутствия любых будущих багов.

## Outcome criteria

- Повторный smoke-тест в runtime оператора закрывает все шесть замечаний с доказательствами и регрессиями; оператор подтверждает удобство.
- Сравнимые замеры до/после подтверждают снижение локальной задержки старта подагента и входной нагрузки короткого ответа без потери контрольных фактов и защит.

## Out of Scope

Переписывание shell целиком, несвязанные flow, автоматическое включение external или изменение разрешений/credentials ради тестов. Закрытие без ручного retest исключено.
