# Tasks

Task definitions live here; task **statuses** live in flow.json and are managed
only via `keryx flow task done <id> <taskId>`.

| ID | Kind | Title |
|----|------|-------|
| T1 | context | Collect remaining context and current evidence posture |
| T2 | implement | Add production guard and real opt-in readiness documentation |
| T3 | test | Validate docs and artifact references for consistency |
| T4 | review | Self-review and prepare completion report |
