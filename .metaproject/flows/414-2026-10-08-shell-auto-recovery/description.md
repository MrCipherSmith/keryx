# Shell automatically resumes interrupted agent turns after connectivity or provider recovery

Status: formalized
Source: user description

## Problem

При обрыве связи или отказе провайдера shell завершает текущий ход и ждёт ввода «продолжай», даже после восстановления. Пример: `[error] OpenAI API returned HTTP 403`. Обычный provider_error заканчивает runAgentTurn; retryable не запускает восстановление.

## Expected Outcome

Эффект: агент не должен ждать действия от пользователя при обрыве и восстановлении связи или падении и восстановлении провайдера. Активный интерактивный ход автоматически ждёт восстановления и продолжает без нового сообщения пользователя.

Выполненные tools, история, approvals и бюджеты сохраняются. Ожидание прозрачно и отменяемо. Постоянный запрет доступа требует исправления, а не бесконечных повторов: общий HTTP 403 не доказывает временность.

## Outcome criteria

- Fault-injection network/429/5xx сценарии завершаются после восстановления при нуле дополнительных сообщений пользователя в readline и TUI.
- Длительный сбой не возвращает ожидание «продолжай» после короткой серии retries; частота запросов ограничена, UI отзывчив, отмена немедленная.
- Выполненные tools не повторяются; approvals и бюджеты не сбрасываются.

## Out of Scope

- Восстановление после завершения процесса shell; переключение аккаунта/провайдера; обход запретов доступа.
- Изменение unattended/print/subagent режимов без отдельного решения; exactly-once гарантия внешних эффектов при неизвестном исходе tool.
