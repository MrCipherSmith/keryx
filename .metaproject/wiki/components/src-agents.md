# Module src/agents

VerifiedAt: 4e80355f1b9fa8576742d151d54397abbd527b38

## Overview

`src/agents` also hosts (in `src/agents/bootstrap.ts`, re-exported through `src/agents/service.ts`) the global agent-bootstrap lifecycle: it installs, checks, and removes a managed Metaproject routing block inside each supported AI coding agent's global instruction file (e.g., `~/.claude/CLAUDE.md`, `~/.config/opencode/AGENTS.md`).

### Supported Agent Runtimes

The module supports five runtimes:

| Runtime | ID | File Name | Default Path |
|---------|-----|-----------|--------------|
| Claude Code | `claude` | `CLAUDE.md` | `~/.claude/` |
| OpenCode | `opencode` | `AGENTS.md` | `~/.config/opencode/` |
| ZCode | `zcode` | `AGENTS.md` | `~/.zcode/` |
| Codex | `codex` | `AGENTS.md` | `~/.codex/` |
| Antigravity | `antigravity` | `AGENTS.md` | `~/.config/antigravity/` |

The module uses HTML comment sentinels to demarcate the block it controls, enabling safe upsert or removal without disturbing user-authored content.

## Architecture

### Two-Layer Design

**Lower Layer — Registry**

`AgentBootstrapRuntime` descriptors are immutable value objects that capture:

- `id` — stable runtime identifier
- `label` — human-readable name
- `aliases` — CLI-acceptable synonyms
- `fileName` — `AGENTS.md` or `CLAUDE.md`
- `filePath(homeRoot)` — resolver function returning absolute path

**Upper Layer — Async Operations**

- `agentBootstrapStatus` — read bootstrap block status
- `installAgentBootstrap` — write bootstrap block to file
- `uninstallAgentBootstrap` — remove bootstrap block from file

### Block Manipulation

Private functions in `bootstrap.ts` handle file content:

- `extractManagedBlock` — locates sentinel-delimited region in a string
- `removeManagedBlock` — strips block and collapses excess blank lines
- `upsertManagedBlock` — removes existing block, then inserts fresh one near top (after YAML front-matter and leading `#` heading) via `insertBlockNearTop`

The bootstrap block text is generated by `renderAgentBootstrapBlock`, which delegates to `renderGlobalMetaprojectBootstrapBlock` in `src/lib/agent-entrypoint-blocks.ts`.

### I/O

Reads use Node's `fs/promises`; writes go through `writeContained` from `src/lib/contained-write.ts`, rooted at the home directory.

## Key Concepts

### Managed Block

The region of an agent instruction file delimited by:

```html
<!-- keryx:global-bootstrap -->
[block content]
<!-- /keryx:global-bootstrap -->
```

Keryx owns only this region; everything outside it is user content.

### AgentBootstrapStatus

Read-only view of an agent file:

| Field | Description |
|-------|-------------|
| `runtime`, `label`, `filePath` | Runtime ID, display label and resolved file path |
| `exists` | Whether the file exists on disk |
| `installed` | Whether the sentinel is present |
| `current` | Whether the installed block matches current keryx rendering |

### Install/Uninstall Results

`AgentBootstrapInstallResult` and `AgentBootstrapUninstallResult` extend `AgentBootstrapStatus` with:

- `wrote` / `removed` — whether the file was modified
- `dryRun` — when `true`, status is computed from would-be content rather than disk

## Public API

### Constants

- `AGENT_BOOTSTRAP_START` — opening sentinel string
- `AGENT_BOOTSTRAP_END` — closing sentinel string
- `AGENT_BOOTSTRAP_SENTINEL` — sentinel identifier string (`keryx-global-bootstrap`)
- `AGENT_BOOTSTRAP_RUNTIMES` — array of all runtime descriptors

### Types

- `AgentBootstrapRuntimeId` — union type of runtime IDs
- `AgentBootstrapRuntime` — runtime descriptor interface
- `AgentBootstrapStatus` — read-only status interface
- `AgentBootstrapInstallResult` — install operation result
- `AgentBootstrapUninstallResult` — uninstall operation result

### Functions

- `agentBootstrapRuntimeIds()` — returns array of all runtime IDs
- `renderAgentBootstrapBlock(fileName?)` — generates bootstrap block text
- `resolveAgentBootstrapRuntimes(ids)` — resolves CLI input (IDs, aliases, `all`) to `{ runtimes, unknown }`
- `agentBootstrapStatus(runtime, homeRoot?)` — checks bootstrap block status
- `installAgentBootstrap(runtime, { homeRoot?, dryRun? })` — installs bootstrap block
- `uninstallAgentBootstrap(runtime, { homeRoot?, dryRun? })` — removes bootstrap block

## Usage Examples

### Check Bootstrap Status

```typescript
const { runtimes } = resolveAgentBootstrapRuntimes(['claude']);
const status = await agentBootstrapStatus(runtimes[0]);
// { runtime: 'claude', label, filePath, exists: true, installed: true, current: false }
```

### Install Bootstrap

```typescript
const result = await installAgentBootstrap(runtimes[0], { dryRun: false });
// { ...status, wrote: true, dryRun: false }
```

### Resolve Runtime Identifiers

```typescript
const { runtimes, unknown } = resolveAgentBootstrapRuntimes(['claude', 'all', 'invalid']);
// runtimes: [Claude, OpenCode, ZCode, Codex, Antigravity]
// unknown: ['invalid']
```
