## Параллельность

Этап 0: M01 и M10 — независимые test/implement workers. Этап 1: HTTP/parser и security/health допускают отдельные ownership. Этап 2: graph и testing/memory — по независимым данным. Этапы 3/4 строят общий wiki contract последовательно, внутренние независимые задачи параллельно. Этап 6: offline runner может готовиться независимо от write batch; write batch ждёт CAS. Этап 7: dependency inventory/seams возможно заранее, перенос клиента после contracts.

Межflow DAG не выдаётся за встроенную гарантию CLI: root читает prerequisites и evidence перед dispatch. Одновременно до трёх workers; git и общие файлы сериализуются.

## Приёмка
